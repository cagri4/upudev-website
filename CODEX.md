# CODEX SESSION PROTOCOL

## Purpose
This file is the mandatory entry point for each new coding session in this repo.

## Startup Checklist (always run in order)
1. Read `CODEX.md`.
2. Read `MASTER_PLAN.md`.
3. Read latest entry in `WORKLOG.md`.
4. Run `git status --short --branch` (if repo exists).
5. Continue from the single `IN_PROGRESS` task only.

## Working Rules
- Keep exactly one active task in `MASTER_PLAN.md`.
- At each checkpoint, append/update `WORKLOG.md`.
- If scope changes, update plan before editing code.
- If blocked, mark task `BLOCKED` with reason and next action.

## Session End Checklist
1. Update `MASTER_PLAN.md` statuses.
2. Add a new `WORKLOG.md` entry.
3. Write explicit "Next first step" and resume command.
